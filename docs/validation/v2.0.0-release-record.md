# PLC Scope v2.0.0 Release Record

## Decision

- Version: `2.0.0`
- Decision date: 2026-07-18
- Disposition: publication approved with the itemized unimplemented and unverified scope below
- Approval: the maintainer explicitly approved each listed disposition before publication
- Live PLC communication for this release: not performed

## Included Changes

- Move the application, tests, build scripts, publish profile, and release workflow to .NET 10 LTS.
- Remove `commentCsvPath` and `commentCsvPaths` from project persistence without migration or fallback.
- Load comment CSV data only after explicit import in the current session and keep CSV-derived comments out of saved watch items.
- Include the PLC communication package and explicit API updates already present in the `Unreleased` changelog.

## Verification Evidence

- .NET 10 Release tests: Core 233 passed, App 63 passed, UI automation 37 passed; 333 total with zero failures.
- `win-x64` self-contained single-file publish completed and produced `PlcScope.exe`.
- Package vulnerability audit reported no known vulnerable direct or transitive packages.
- Package deprecation audit still reports `xunit` 2.9.3 as Legacy; this is an accepted remaining maintenance item, not a passed check.
- Managed Markdown, JSON, and workflow files contain no maintainer PC-specific absolute path.
- Project JSON regression tests verify that removed comment CSV fields are not saved and do not trigger legacy file access.
- Shift-JIS comment CSV decoding is covered after removal of the redundant direct `System.Text.Encoding.CodePages` package reference.
